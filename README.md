Generate photos with a 25_ji_nightcord_de style!

## Feature

通过输入文字生成「25时，在Nightcord。」团体 Logo 风格的图片。

生成图片使用的字体有：思源宋体【简体中文】、思源宋體【繁體中文】、源ノ明朝【日本語】。
